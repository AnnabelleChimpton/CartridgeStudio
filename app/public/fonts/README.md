# Fonts for the print PDF

Embedded (subset) in the box, label and manual PDF. Both fonts are licensed
under the SIL Open Font License 1.1, which allows embedding.

| File | Font | License |
| --- | --- | --- |
| `press-start-2p.ttf` | Press Start 2P (titles) | `press-start-2p-OFL.txt` |
| `atkinson-hyperlegible-regular.ttf`, `-bold.ttf` | Atkinson Hyperlegible (text) | `atkinson-hyperlegible-OFL.txt` |

Copied unmodified from the `@expo-google-fonts/press-start-2p` and
`@expo-google-fonts/atkinson-hyperlegible` 0.4.1 packages (Google Fonts
releases). TrueType rather than WOFF2: pdf-lib can only subset and embed
TrueType/OpenType outlines.
