Built with 7800basic by Mike Saarna (RevEng) and dasm.

About this page

This page holds a 7800 game made with Cartridge Studio and the js7800 emulator that plays it, so it needs no internet and sends nothing anywhere. Not affiliated with or endorsed by Atari.

js7800 here is built from upstream commit fe918ce, with its audio and mouse modules swapped for two small stand-ins so it runs in a worker, then minified. The stand-ins and the build script are in Cartridge Studio's source (app/js7800-core/ and app/scripts/build-js7800.mjs).

With a gamepad: Start pauses, Select plays again from the start, and holding Select for a second leaves full screen.
